1 · Resumen ejecutivo

Los datos existen, pero están dispersos y detrás de barreras

Se hizo una investigación activa para identificar, acceder, verificar y descargar los datos hídricos públicos de Guatemala.

La misión funcionó como un proceso de ingeniería de datos en tiempo real, no como un estudio de gabinete. Se sondearon APIs oficiales, se examinaron servidores gubernamentales y académicos, se eludieron barreras de visualización y se descargaron 155.55 MB de datos brutos y procesados, organizados con checksums SHA-256 verificables.

El ecosistema estatal de datos abiertos está fragmentado y tiene barreras perimetrales (WAF/Cloudflare). Aun así, hay conjuntos de datos cuantitativos de alta resolución espacial y temporal muy valiosos.

Lo más valioso que se encontró

  • INSIVUMEHRegistros diarios de la red hidrométrica, con estaciones activas en los ríos Motagua y Las Vacas.
  • HydroRIVERSMás de 23,000 tramos fluviales vectorizados con caudales modelados.
  • The Ocean Cleanup / USACMonitoreo empírico de macroplásticos, 2019–2024.
  • ERIS-USAC · 2025Contaminantes emergentes farmacéuticos medidos por espectrometría de masas (HPLC-MS/MS).

5 · Brechas y obstáculos

Lo que no se pudo obtener, y por qué

  1. 0 estacionesSin datos

    Guatemala no aparece en UNEP GEMStat (GFQA v3)

    Se inspeccionó el archivo maestro global de 201 MB y 84 parámetros. Las 129 estaciones de la ventana geográfica pertenecen a la frontera de México. Confirma una desconexión histórica entre el Estado y los repositorios globales de calidad del agua.

  2. HTTP 403Bloqueo

    Portales del Estado bloquean peticiones automatizadas

    marn.gob.gt y el catálogo oficial datos.gob.gt devuelven 403 Forbidden por WAF/Cloudflare. No se puede cosechar datos de forma continua vía APIs públicas.

  3. Timeout :80Sin acceso

    Geoserver de SEGEPLAN (IDEG) inaccesible

    El servicio WFS/WMS no responde desde fuera. Las capas geoespaciales solo se obtienen con descarga manual desde la web.

  4. Sin publicarOpacidad

    Operadores de agua potable y saneamiento

    Ni EMPAGUA ni los operadores municipales publican bases abiertas de calidad del agua cruda o tratada en sus fuentes (planta Lo de Coy, pozos metropolitanos).

  5. Solo agregadosDatos retenidos

    Registros privados de limpieza industrial

    Alianza Motagua y 4ocean publican cifras agregadas o de relaciones públicas. Retienen las matrices diarias de pesaje y composición gravimétrica.

    • Next.js / React + MapLibre GL o Deck.glVisor 3D del relieve y la red de drenaje. Permite navegar por tramo, ver el flujo de plásticos y consultar contaminantes en Las Vacas y el Motagua.
